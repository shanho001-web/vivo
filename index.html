模組一：開發環境建置

歡迎加入！第一步，我們要把你的電腦變成專業的開發環境。

步驟清單：

  1. 下載並安裝 Visual Studio Code。
  2. 安裝必備擴充套件：在左側積木圖示搜尋並安裝 Live Server。
  3. 建立專案資料夾並將其拖曳至 VS Code 開啟。
🔴 注意： 開發過程中請確保檔案名稱全為英文小寫，避免伺服器讀取錯誤。

模組二：JavaScript 基礎四部曲

這裡是基礎語法速查表，請隨時回來複習：

1. 變數 (Variables)

let userName = "員工A"; // 可變更的變數
const company = "我們的公司"; // 不可變更的常數

2. 資料型態 (Data Types)

let age = 25; // 數字 (Number)
let isPass = true; // 布林值 (Boolean)

3. 陣列與物件 (Arrays & Objects)

let skills = ["HTML", "CSS", "JS"]; // 陣列
let employee = { name: "員工A", role: "Junior" }; // 物件

4. 算術運算子 (Operators)

let total = 10 + 5; // 加法，結果為 15
let remainder = 10 % 3; // 餘數，結果為 1

模組三：GitHub 版本控制

寫好的程式碼必須上傳到 GitHub 進行備份與團隊協作。

操作流程：

  1. 至 GitHub 官網註冊帳號。
  2. 在 VS Code 終端機 (Terminal) 輸入初始設定指令。
  3. 使用 git add . 與 git commit -m "更新說明" 儲存變更。
  4. 使用 git push 上傳至雲端。
🔴 資安鐵律： 絕對不可以將任何密碼、API 金鑰 (API Keys) 直接寫在程式碼中並上傳到 GitHub！

模組四：Vercel 部署與 LLM 流程標準

我們的標準部署流程使用 Vercel，並整合 AI (LLM) 功能。

1. Vercel 伺服器部署

  • 註冊 Vercel 帳號並綁定你的 GitHub。
  • 在 Vercel 後台選擇你的專案 Repository，點擊 Deploy，即可獲得正式網址。

2. 串接 AI (LLM) 準備工作

  • 未來我們將使用 Vercel AI SDK 來串接大型語言模型。
  • 你需要去對應的平台（如 OpenAI 或 Google AI Studio）申請 API Key。
  • 金鑰存放位置： 金鑰必須存放在 Vercel 專案後台的 Environment Variables (環境變數) 中，切勿寫在本地檔案裡！
