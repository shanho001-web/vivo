模組一：開發環境與工具建置全攻略

歡迎加入團隊！本章節將帶領你從零開始，將你的筆記型電腦打造成標準、高效的現代化軟體開發工作站。

1. 核心編輯器安裝 (VS Code)

Visual Studio Code 是目前業界標準的程式碼編輯器。請前往官網下載對應系統的版本並完成安裝。

2. 必備擴充套件 (Extensions) 推薦

  • Live Server： 用於在本地啟動即時預覽伺服器，修改網頁後會自動重新整理。
  • GitLens： 強化版本控制歷史紀錄的視覺化工具。
  • Prettier： 自動排版與美化程式碼的格式化工具。

3. 檔案命名與資料夾鐵律

🔴 絕對注意：
  • 所有專案檔案與資料夾名稱必須全為英文小寫，嚴禁使用中文或空格。
  • 網頁主檔案必須命名為 index.html，否則伺服器無法正確識別首頁。

模組二：JavaScript 核心語法與邏輯

JavaScript 是網頁開發的靈魂。以下是我們在日常開發中最常用、最重要的核心語法速查與規範：

1. 變數與常數宣告 (Let vs Const)

永遠優先使用 const 來宣告不會被修改的常數；若數值需要變動，才使用 let。

let currentScore = 10; // 數值會隨遊戲或邏輯改變
const API_URL = "https://api.vivo.com"; // 固定的伺服器連線網址

2. 常用資料型態 (Data Types)

let employeeName = "張三"; // 字串 (String)
let employeeAge = 28;     // 數字 (Number)
let isVerified = true;    // 布林值 (Boolean - True/False)

3. 陣列與物件結構 (Arrays & Objects)

// 陣列：用來儲存清單資料
let techStack = ["HTML", "CSS", "JavaScript", "Git"];

// 物件：用來描述單一實體的詳細屬性
let staffProfile = {
    name: "李小明",
    role: "Frontend Developer",
    active: true
};

4. 條件判斷與函式 (Conditionals & Functions)

function checkAccess(age) {
    if (age >= 18) {
        return "允許進入系統";
    } else {
        return "權限不足";
    }
}

模組三：GitHub 版本控制與協作鐵律

版本控制是多人開發的生命線。我們必須養成良好的 Commit 習慣，確保所有變更都有跡可循。

1. 標準更新三部曲 (終端機指令)

當你在本地完成程式碼修改後，必須在 VS Code 終端機依序執行以下三個指令：

git add .                  # 將所有修改過的檔案加入暫存區
git commit -m "更新說明文字" # 替這次修改留下清晰的紀錄備忘
git push                   # 將本地程式碼安全推送到遠端 GitHub 雲端

2. 團隊開發鐵律

🔴 資安與維護最高守則：
  • 絕對禁傳密鑰： 任何密碼、資料庫密鑰、AI API Key 絕對不能寫在程式碼裏面並 Push 到 GitHub！
  • 增量開發： 所有修訂必須在既有穩定的基礎上進行擴充，不可無故刪除已完成的穩定邏輯。

模組四：Vercel 雲端部署與 AI (LLM) 串接

本專案採用最現代化的雲端架構，結合 Vercel 進行秒級自動化部署，並串接大型語言模型 (LLM) 實現智慧化功能。

1. Vercel 自動化雲端部署流程

  • 將專案推送到 GitHub 後，登入 Vercel 官方網站並連結你的 GitHub 帳號。
  • 點擊 Import Project 匯入你的專案儲存庫。
  • 點擊 Deploy，系統會自動在幾秒內完成建置，並配發一個專屬的 *.vercel.app 雲端網址供手機與電腦隨時訪問。

2. 串接 AI 與環境變數 (Environment Variables) 安全設定

為了安全起見，所有機密金鑰必須妥善安置：

  • 取得金鑰： 前往官方平台申請專屬的 AI API Key。
  • 設定位置： 進入 Vercel 後台的 Settings ➔ Environment Variables，將金鑰名稱與數值安全填入。
  • 程式碼後端透過環境變數安全讀取，確保對外公開的 GitHub 程式碼絕對安全無虞。
