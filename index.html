模組一：開發環境建置

歡迎加入！第一步，我們要把你的電腦變成專業的開發環境。

步驟清單：

  1. 下載並安裝 Visual Studio Code。
  2. 安裝必備擴充套件：在左側積木圖示搜尋並安裝 Live Server。
  3. 建立專案資料夾並將其拖曳至 VS Code 開啟。
🔴 注意： 開發過程中請確保檔案名稱全為英文小寫，避免伺服器讀取錯誤。

模組二：JavaScript 基礎四部曲 (詳細指令版)

這裡是網頁互動的靈魂，以下涵蓋了你必須掌握的詳細指令與邏輯寫法：

1. 變數與資料型態

let employeeName = "王小明"; // 字串
const companyID = "HK001"; // 宣告常數 (不可變更)

2. 算術與邏輯運算

let sum = 10 + 5;
if (sum >= 15) { console.log("達標！"); }

3. 陣列與物件

let frontendSkills = ["HTML", "CSS"];
frontendSkills.push("JavaScript"); // 加入新資料

4. 函式與指令

function calculateSalary(base, bonus) {
    return base + bonus; 
}

模組三：GitHub 版本控制

寫好的程式碼必須上傳到 GitHub 進行備份與團隊協作。

日常更新三部曲：

git add .
git commit -m "你的更新說明"
git push
🔴 資安鐵律： 絕對不可以將任何密碼、API 金鑰直接寫在程式碼中並上傳！
