vivo 培訓中心

第一步：環境準備

請確認以下軟體皆已安裝：

  • 安裝 VS Code (編輯器)
  • 設定 Node.js 環境
  • 配置 Git 身份認證 (Name & Email)

第二步：開發規範

我們的程式碼必須遵循以下規則：

  1. 檔案名稱全用英文小寫。
  2. 變數命名採用 camelCase (例如：userName)。
  3. 每個功能必須有詳細註解。

第三步：更新協作流程

每天工作結束前，必須執行：

git add .
git commit -m "更新內容描述"
git push
